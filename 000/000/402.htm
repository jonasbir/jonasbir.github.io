Johan Wilhelm Wickström, född 1752 (åu - ej i fb, omnämns i hsf för Hamneda 1798-1808 som född 1738, vilket sannolikt är en felaktig uppgift, källa: Genline ID 828.4.26300); trumslagare vid Kronobergs reg:te; † 1812-03-08 på Ringshults backstuga, Västra Torsås sn, begr 15/3 (avskedad gift trumslagare, bröstfeber, 60 år gammal, källa: Genline ID 849.21.17100). Gift 1:o: med Anna Margareta Lindberg, † omkr 1794 i Hamneda sn (ej i db). 2:o 1800-04-13 i Kalvsviks sn (källa: Genline ID 234.20.800) med sin brors svägerska, jungfrun Hedvig Beata Liljegren, (kallas Svensdotter i fb för Västra Torsås sn 1811, källa: Genline ID 849.21.5400) född 1771-11-06 på Önnestad, Önnestads sn, dpt 9/11 (källa: Genline ID 1451.43.52400 och 849.21.17100. Står även skriven med syster och svåger på Kalvsviks Thorsagård i Kalvsviks sn vid hsf 1775-1790, källa: Genline ID 234.3.36100), dotter till rusthållaren Sven Larsson Liljegren och Brita Sophia Meck (Brita Sophia var syster till Emerentia Catharina Meck, som var gift med kornetten Johan Christian Scheibe - Christian Georg Wickströms morbror).
